# 💱 Currency Converter

A simple and responsive Currency Converter web application built using HTML, CSS, and JavaScript.  
This project allows users to convert currencies in real-time using live exchange rates.

## 🚀 Features

- Convert currencies instantly
- Real-time exchange rates
- Country flags support
- Responsive and clean UI
- Easy to use interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Exchange Rate API
